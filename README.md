# TapTap Landing Page
模仿 TapTap 的产品落地页，静态单页面网站，使用 Tailwind CSS + GSAP + tsParticles 实现动画效果。

✅ 在线预览：https://alchemy9.github.io/taptap-landing/

## 技术栈
- HTML5
- Tailwind CSS CDN
- Font Awesome
- GSAP / ScrollTrigger
- Lenis 平滑滚动
- Vanilla‑Tilt
- tsParticles 粒子效果
